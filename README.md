Screen-to-Dispatch

A Chrome browser extension that lets Prospectr team members select an element on a website, describe the desired change, and send a structured edit request to Dispatch.

Install in Chrome

1. Download Screen-to-Dispatch file
2. Navigate to chrome://extensions.
3. Turn Developer mode on in the top right corner
4. Click Load Unpacked
5. Select Screen-to-Dispatch file
6. The Screen-to-Dispatch extension should appear in Chrome

How It Works:

Navigate to a website in Chrome.
Click the Screen-to-Dispatch extension icon.
Select the element you want to change.
Enter the requested change.
Click Send to Dispatch.
The extension sends a structured request to Dispatch.
